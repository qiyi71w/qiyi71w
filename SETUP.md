# Setup

Create the public profile repository `qiyi71w/qiyi71w` and copy this bundle into it.

`wimi321/lizzieyzy-next` uses contributor mode. Every Current Work run queries GitHub
for `qiyi71w`'s merged PR count, open PR count, and latest PR, so these values stay live.

Add an Actions secret named `METRICS_TOKEN` for lowlighter/metrics, then manually run
Current Work, Metrics, and Snake once.
